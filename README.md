Task28- Decision Tree Classifier

## Objective
To train a Decision Tree Classifier and understand how tree depth and other parameters affect model performance.

## Dataset
Iris Dataset

The Iris dataset contains 150 observations with four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target contains three Iris species.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Steps Performed
1. Loaded the Iris dataset.
2. Explored the dataset.
3. Checked for missing values.
4. Split the dataset into training and testing sets.
5. Built a Decision Tree Classifier.
6. Evaluated model accuracy.
7. Generated a classification report.
8. Created a confusion matrix.
9. Visualized the decision tree.
10. Compared model performance across different tree depths.
11. Analyzed overfitting.
12. Examined feature importance.

## Conclusion
The Decision Tree Classifier successfully classified the Iris dataset. Different tree depths were tested to understand model complexity and overfitting. Feature importance was also analyzed to identify the most useful features for classification.
